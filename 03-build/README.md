# 03 · Build

How the product got made, kept alongside the product.

```
prompts/        One file per build stage, in sequence
decisions.md    Choices made mid-build and why — the ones you'd be asked about
```

The prompts are worth keeping for the same reason commit messages are: they
record intent, not just outcome.

A useful tell — if a prompt is explaining *how something should behave*
(what a layout does at a width, how a modal opens), that rule was missing from
`02-system/` and should be written back into it.
