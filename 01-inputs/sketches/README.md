# Sketches

iPad sketches and rough screens — the earliest, roughest layer of an idea,
before it's a moodboard reference or a build prompt.

**What goes here:** photos of pen-and-paper drawings, iPad sketches, whiteboard
shots, rough boxes showing where things sit on a screen. Anything drawn by hand
before pixels.

**Naming:** by surface and pass — `dashboard-v1.jpg`, `application-form-v2.png`.

If a sketch drives a specific build stage, reference the filename in the
relevant `03-build/prompts/0X-*.md`.

This folder is empty until you draw something. That's normal — it fills up at
the start of a project, not the end.
