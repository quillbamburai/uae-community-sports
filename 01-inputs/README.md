# 01 · Inputs

Everything gathered before building. This is the thinking layer — none of it
ships, all of it shapes what does.

```
moodboard/      Visual references, tagged by what you're taking from each
sketches/       iPad sketches, rough screens, whiteboard photos
references/     Products doing something similar, data-vis examples, patterns
brand-assets/   Logos, supplied fonts, existing brand files
```

`moodboard.md` sits alongside the images with a note per reference: not "this
looks nice" but what specifically you're taking — a layout idea, a density, a
way of handling state.

The point of this folder is that direction is **established here**, not
discovered mid-build.
